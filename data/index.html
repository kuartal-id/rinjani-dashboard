AGENCY DESK

Publish a dataset

The file stays in this browser until an agency server is connected. The columns decide what we can draw. Anything else is kept as a table and is not charted.

To draw a map

CSV or GeoJSON. Each place needs a name and coordinates. A note is optional.

  • name or nama
  • latitude or lat, lintang
  • longitude or lng, lon, bujur
  • note optional, or catatan
Download a point template

To draw a chart

CSV with one label column and one numeric column. Up to 500 rows.

  • label or kategori, nama
  • value or nilai, jumlah
Download a chart template
